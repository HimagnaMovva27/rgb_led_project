# RGB LED Control using Arduino

## Description

This project demonstrates how to control an RGB LED using Arduino.

## Components Used

* Arduino Uno
* RGB LED
* Resistor
* Jumper wires

##  Working

The Arduino uses PWM signals to control Red, Green, and Blue pins, producing different colors.
